# Arduino LED Blink

### 1. LED Blink
A basic Arduino program that blinks the built-in LED at one-second intervals using digital output control.

**File:** `LED_Blink.ino`

**Concepts:** `pinMode()`, `digitalWrite()`, `delay()`

### 2. Three LED Blink
An Arduino program that controls three LEDs connected to digital pins 8, 9, and 10, turning them ON and OFF sequentially at one-second intervals.

**File:** `3_LED_Blink.ino`

**Pins:** Red – 8 | Yellow – 9 | Green – 10

**Concepts:** Digital GPIO, multiple outputs, sequential control

## Hardware
